# Генерация растровых штрихкодов

Проект - библиотека на c++, предоставляющая инструменты для генерации PNG, SVG, BMP штрихкодов форматов:

- Code 128
- Code 39
- Data Matrix Code
- QR Code
- EAN Code


## Ближайшие цели

- [x] Реализовать Code 128
- [x] Реализовать Code 39

- [x] Реализовать QR Code
- [x] Реализовать EAN Code
- [x] Реализовать единый API для генерации

- [ ] Unit - тесты
