# Генерация растровых штрихкодов

Проект - библиотека на c++, предоставляющая инструменты для генерации PNG, SVG, BMP штрихкодов форматов:

- Code 128
- Code 39
- Data Matrix Code
- QR Code
- EAN Code

## Структура проекта

## Code 128
Для использования библиотеки в коде необходимо настроить функции из библиотеки в файле, где эти функции будут использоваться.  

Каждый символ кодируется 11 чередующимися чёрно-белыми полосами (3 штриха и 3 пробела, каждый от 1 до 4 модулей).

### Описания ключевых моментов реализации

Один допустимый формат файла: PNG

Для генерации PNG используется библиотека stb_image_write

## Code 39

Каждый символ кодируется 9 чередующимися черно-белыми полосами разной ширины (в коде последовательность 0 и 1: 1 - широкая полоса, 0 - узкая) 

### Описания ключевых моментов реализации
Три допустимых формата файлов: PNG, SVG, BMP

Для генерации PNG файлов используется библиотека **stb_image_write**

## Data Matrix Code

Для использования библиотеки в коде необходимо настроить функции из библиотеки в файле, где эти функции будут использоваться.

Каждый символ Data Matrix представляет собой двумерную матрицу из чередующихся чёрно-белых модулей (квадратных ячеек). Размер матрицы варьируется от 10×10 до 144×144.
### Описания ключевых моментов реализации

Один допустимый формат файла: BMP

Для генерации BMP используется самописный модуль без сторонних библиотек.

## QR Code
```cpp
int generateQRCodePNG(const char* text, const char* filename, int scale);
```
### Параметры

- **`text`** — текст для кодирования
- **`filename`** — путь к выходному файлу
- **`scale`** — размер одного модуля в пикселях

### Уровни коррекции ошибок

|---------|----------------|
| `LOW` | 7% |
| `MEDIUM` | 15% (по умолчанию) |
| `QUARTILE` | 25% |
| `HIGH` | 30% |

## EAN Code
Архитектура:
Проект построен по принципам ООП с разделением ответственности:
Класс	Назначение
BarcodeGenerator	Абстрактный базовый класс для всех типов штрих-кодов
EAN13Code	Реализация стандарта EAN-13 (наследует BarcodeGenerator)
ImageWriter	Низкоуровневая запись пиксельных данных в PNG
BarcodeRenderer	Преобразование двоичного паттерна в изображение
BarcodeApplication	Управление пользовательским интерфейсом и потоком выполнения



### Описания ключевых моментов реализации
Алгоритм контрольной суммы EAN-13:

Суммировать цифры на нечётных позициях (считая с 0)
Суммировать цифры на чётных позициях и умножить на 3
Сложить оба результата
Контрольная цифра = (10 - (сумма % 10)) % 10

Ключевые особенности реализации
Абстрактный базовый класс	позволяет добавлять новые типы штрих-кодов (UPC, Code128)
Статические таблицы кодирования	L_CODES, G_CODES, R_CODES — неизменяемые данные
Автоматический выбор кодировки	по первой цифре определяется карта чётности
Гибкие параметры рендеринга	настраиваемые moduleWidth, barHeight, quietZone
C++17 features	std::filesystem, std::make_unique, static_cast
Без внешних зависимостей	Только stb_image_write.h (однозаголовочная библиотека)
